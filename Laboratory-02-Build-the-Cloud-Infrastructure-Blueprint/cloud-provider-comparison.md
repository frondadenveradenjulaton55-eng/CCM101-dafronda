# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

## 1. Which cloud provider offers the broadest range of services?

AWS is commonly recognized as having a very broad range of cloud services. It provides services covering compute, storage, networking, databases, security, analytics, and many other areas.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a strong choice because it integrates closely with Microsoft's products and enterprise technologies.

## 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

Google Cloud is widely recognized for AI and machine-learning capabilities and Kubernetes services.

## 4. What similarities did you observe among the three cloud providers?

All three providers offer compute, storage, networking, and identity/access-management services. They also provide scalable cloud infrastructure and tools for managing resources.
