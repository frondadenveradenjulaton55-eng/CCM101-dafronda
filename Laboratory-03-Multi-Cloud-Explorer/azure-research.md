# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

## Global Infrastructure

Azure operates through a worldwide infrastructure organized into regions and availability zones. Organizations can select suitable locations based on factors such as latency, availability, compliance, and data residency.

## Cloud Management Console

The Azure portal is a web-based management interface for creating and managing Azure resources. Administrators can use the portal to manage virtual machines, storage, networking, identity, databases, and other cloud services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers that can run Windows or Linux operating systems. They are useful for applications that require control over the operating system and virtual machine environment.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application files.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks for Azure resources. It provides networking features such as subnets, IP addresses, routing, and network security.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and resources. It is especially useful for organizations already using Microsoft services and technologies.

## Three Advantages

### 1. Microsoft Integration

Azure integrates closely with Microsoft products such as Windows Server, Microsoft 365, and Microsoft identity services.

### 2. Enterprise Features

Azure provides services and management capabilities designed for organizations with complex IT environments.

### 3. Global Infrastructure

Azure provides cloud infrastructure in multiple geographic regions, allowing organizations to select locations suitable for their applications.

## Typical Enterprise Use Cases

Azure is commonly suitable for Windows-based applications, enterprise systems, Microsoft 365 environments, hybrid cloud deployments, databases, business applications, and identity management.
