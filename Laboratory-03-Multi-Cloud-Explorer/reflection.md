# Mission 3 Reflection

This activity helped me understand that AWS, Microsoft Azure, and Google Cloud provide similar fundamental cloud capabilities, but each platform has different strengths. Before this activity, I mostly viewed cloud computing as simply running applications on remote servers. After comparing the three providers, I learned that cloud platforms also include storage, networking, identity management, databases, containers, analytics, and artificial intelligence services.

The platform that impressed me most was Google Cloud because of its strong focus on data, artificial intelligence, machine learning, and Kubernetes. I found its services particularly interesting for organizations that develop modern applications and work with large amounts of data. However, this does not mean that Google Cloud is always the best choice because the appropriate provider depends on the organization's requirements.

AWS, Azure, and Google Cloud have several similarities. All three provide virtual machines, object storage, virtual networking, identity and access management, databases, and container services. They also use geographic regions and availability zones or zones to help organizations design applications for performance and availability.

Business requirements have a major effect on cloud platform selection. A company using Microsoft technologies may benefit more from Azure, while an AI-focused organization may prefer Google Cloud. An organization requiring a broad collection of cloud services may consider AWS. Budget, security, scalability, existing systems, location, and technical skills should also be considered.

Acting as a Cloud Solutions Consultant taught me that selecting a cloud provider is not simply about choosing the most popular platform. The consultant must understand the client's problem first and then match the requirements with suitable services.

Finally, this activity improved my GitHub portfolio because I learned how to organize research, comparison tables, recommendations, screenshots, and technical documentation in one repository. It also gave me practical experience connecting Linux administration concepts with cloud computing.
