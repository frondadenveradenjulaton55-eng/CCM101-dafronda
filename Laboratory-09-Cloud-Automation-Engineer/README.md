
# Lab Activity 9: Cloud Automation Engineer

## Overview

This laboratory activity focuses on automating server maintenance tasks using Bash scripting and Cron jobs. The activity demonstrates how to create backup files, organize application data, and schedule recurring tasks in a Linux environment.

## Objectives

- Understand the purpose of cloud automation.
- Create Bash scripts to automate backup operations.
- Use Cron jobs to schedule recurring tasks.
- Create compressed backup archives using `tar`.
- Verify that backup files are created successfully.

## Commands Used

| Command | Purpose |
|---|---|
| `mkdir` | Creates a directory. |
| `echo` | Displays text or writes text into a file. |
| `nano` | Opens a text editor in the terminal. |
| `chmod +x` | Makes a script executable. |
| `tar -czf` | Creates a compressed archive. |
| `ls -l` | Displays files and their details. |
| `crontab -e` | Edits scheduled Cron jobs. |
| `crontab -l` | Lists configured Cron jobs. |

## Skills Learned

- Basic Bash scripting
- Linux file and directory management
- Automated backup procedures
- Cron job scheduling
- Backup verification and maintenance
