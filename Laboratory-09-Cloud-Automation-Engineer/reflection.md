
# Laboratory Reflection

This activity helped me understand how Bash scripting and Cron jobs can be used to automate routine tasks in a Linux environment. Instead of entering the same commands repeatedly, I learned how to place them inside a script and schedule the script to run automatically.
I learned how to create a backup script, use variables, check directories, compress files, and assign executable permissions. I also learned that Cron can run commands at a specified time without requiring manual execution.
One important part of the activity was ensuring that the script used the correct directory paths. I also learned that a script should be tested manually before it is scheduled. Checking the generated archive is necessary to confirm that the expected files were included.
Automation is useful because it saves time and makes repeated tasks more consistent. Scheduled backups can also help protect important data, provided that the backup process is checked regularly and the backup files are stored securely.
The cloud engineering role I find interesting is Cloud Automation Engineer. This role involves creating scripts and automated workflows that help simplify system administration. Learning Bash and Cron is a useful starting point for understanding how routine cloud operations can be automated.
Overall, this laboratory activity improved my understanding of Linux automation and backup management. I learned that automation is not only about scheduling commands but also about testing scripts, checking results, and ensuring that tasks run using the correct configuration.
