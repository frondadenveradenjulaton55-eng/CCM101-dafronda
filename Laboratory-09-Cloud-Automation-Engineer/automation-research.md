# Automation Research

## Bash Scripting

Bash scripting combines Linux commands into one file to perform tasks automatically. It helps simplify repeated operations and reduces the need to enter commands individually.

## Variables

Variables hold information that a script can use when performing tasks. They make it easier to update settings, such as folder names and file locations, without changing every command.

## Cron Jobs

Cron jobs allow Linux to execute commands automatically according to a schedule. They are useful for recurring tasks, such as creating backups at a specific time.
