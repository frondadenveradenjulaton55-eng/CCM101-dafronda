# Mission Reflection

This laboratory helped me understand how firewall configuration contributes to Linux server security. I learned how UFW rules can control incoming and outgoing traffic and how specific ports can be allowed for required services.

I also learned the importance of the Principle of Least Privilege. A server should provide only the access needed for its intended purpose. Restricting unnecessary ports can help reduce exposure to unwanted connections.

Working with Docker and Nginx also showed me that running a web application involves more than starting a container. Port mappings, firewall rules, and connectivity tests must be considered to ensure that the service works as intended.

The activity also taught me to verify configurations rather than rely only on commands. Checking firewall status, reviewing rules, and testing the web endpoint help identify possible configuration problems.

Overall, this laboratory improved my understanding of basic cloud security practices. Careful firewall management, regular verification, and appropriate access controls are important for keeping services accessible to authorized users while limiting unnecessary network exposure.
