# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege ensures that users and services receive only the permissions required for their tasks. Applying this principle helps prevent unnecessary access and reduces potential security risks if an account or service is compromised.

## Attack Surface

An attack surface includes the parts of a system that could be targeted by unauthorized users. Examples include open network ports, active services, and user accounts with weak security settings. Reducing unnecessary access points can help improve system security.

## Default Deny Policy

A Default Deny policy blocks incoming network connections unless they are explicitly permitted by a firewall rule. This approach helps protect a system by allowing only approved traffic instead of accepting connections by default.
