Laboratory 01 – Welcome to the Cloud

Mission Overview

This laboratory activity introduces the basic Linux environment and prepares a professional Cloud Computing portfolio using GitHub.

Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

Activities Performed

- Accessed a Linux environment using KillerCoda.
- Created and logged in to a new Linux user account.
- Gathered basic system information.
- Created and organized files and directories.
- Created a Cloud Computing portfolio on GitHub.
- Documented the laboratory activity using Markdown.

Skills Learned

I learned basic Linux navigation, user management, system information gathering, file organization, Markdown documentation, Git, and GitHub repository management.
